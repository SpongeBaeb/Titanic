# 돈 쓰기 화면(Q4) 동작 확인 절차

`MoneyMinigameView.tsx`를 고칠 때마다 이 절차를 처음부터 끝까지 돌려서 결과가 같은지 본다.

## 준비
1. 개발 서버(http://localhost:3000)를 열고, **브라우저 탭이 화면에 보이는 상태**에서 한다 (탭이 가려지면 애니메이션이 멈춰 말풍선이 바뀌지 않는다).
2. 콘솔에서 Q4로 바로 간다:
   ```js
   sessionStorage.setItem('titanic.session.v1', JSON.stringify({currentStep:'Q4',answers:{embarked:'S',sex:'male',ageGroup:'18-29',companion:'alone',pclass:2},flags:{},picks:[],extras:{age:25},history:[]})); location.reload();
   ```
3. 아래 `D` 는 `window.__duck` 이다 (개발 서버에서만 있다). **매번 `window.__duck`을 새로 읽는다** (렌더마다 다시 만들어진다).

## 확인 항목
| # | 조작 | 기대 결과 |
|---|---|---|
| 1 | 화면 진입 | 1.2초 뒤 오리 사무장 인사 말풍선 (회차에 따라 문장이 다름) |
| 2 | `D.vfx('bath')` | 거대 비눗방울이 떠다닌다 |
| 3 | `D.vfx('pool')` | 아래에서 물이 차오르고 고무 오리가 뜬다 |
| 4 | `D.vfx('massage')` 후 빈 곳 클릭 | 실사풍 번개(가지, 깜빡임, 하늘 섬광)와 천둥 |
| 5 | `D.vfx('telegraph')` | 오른쪽에 전신기, 왼쪽에서 사무장 동료 오리가 걸어 나와 춤춘다, 사무장 소개 대사 |
| 6 | 전신기 키 누르기 | 호박색 점/선이 왼쪽으로 날아가고, 동료 오리가 머리 높이에서 숙여 피한다 |
| 7 | `D.vfx('barber')` | 가위 커서, 위에서 머리카락. 클릭하면 잘려 물에 떨어지고 고무 오리가 찡그린다 |
| 8 | `D.vfx('souvenir')` | 기념품 4개(칼은 반드시 하나)가 튀어나온다 |
| 9 | `D.pop()` (또는 가위로 거품 클릭, 칼/찻잔을 거품 근처에 놓기) | 거품이 터지고 조각이 흩날림, "…비누 거품이 터졌소" |
| 10 | `D.zap(500)` (또는 번개로 물 클릭) | 수면을 따라 번개가 갈라지고 고무 오리가 감전, "…감전은 보험 적용이 안 되오" |
| 11 | `D.zapS()` (또는 번개로 기념품 클릭) | 찻잔은 깨지고, 칼은 푸르게 빛남 |
| 12 | `D.short()` (또는 번개 능력으로 전신기 근처 클릭) | 전신기가 떨리며 푸르게 빛나고 3초간 신호를 쏟아냄, 동료 오리에게 스포트라이트 |
| 13 | 전신기 위를 직접 클릭(번개 능력 있음) | 번개가 치지 않고 키만 눌림 |
| 14 | `D.sos()` (또는 점3·선3·점3) | 뱃고동, "…구조 요청이오. 아직은 이르오", 업적 "아직은 이른 신호" |
| 15 | 가위로 날아가는 신호 자르기 | 불꽃과 함께 신호가 사라짐, 처음 한 번 사무장 대사 |
| 16 | 기념품을 물 위(화면 아래 15%)에 놓기 | 가라앉지 않고 출렁이며 뜬다 |
| 17 | 칼을 빠르게 던지기 | 화면 밖으로 날아갔다가 반대편에서 돌아온다 |
| 18 | 칼을 오리 사무장 위에 두 번 | 1번째: 권총을 꺼내 겨눔 / 2번째: "기어코 선을 넘네." 발사, 1인칭으로 쓰러진 뒤 사망 문구 |
| 19 | 지폐를 오리 사무장에게 5장 | 1~4장 대사가 달라짐, 5장째 "나는 거지가 아니오!" 뒤 전부 돌려줌, 업적 |
| 20 | `D.drop('gamble')` (25세) | 도박 창이 열린다 |
| 21 | 나이 6세 또는 15세로 2번 준비 후 `D.drop('gamble')` | 도박 창이 열리지 않고 사무장이 돌려보냄 |
| 22 | 기념품을 잡고 끌기 | 뒤의 시설 선반이 같이 돌지 않는다 |
| 23 | 지폐 5장 모두 사용 | "선택 완료" 버튼, 누르면 다음 장면 |
